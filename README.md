# About the game
A **tower defense game** with quite a twist to it - **the game literaly evolves around you**. You start out with nothing but a single corrupted tree that's weak and are set out on the quest of helping fix the game.
Something went wrong while exporting the game, the files got corrupted... Now you have to help "Null" defend the unaffected files from the corrupted ones while they rework the game

## How can I play this?
Well I've tried my best to make a working web version to make the game as easy to play as possible, but videos just straight up refuses to work in the web.

# Content
The game features:
- **5 fully completeable worlds**, each one featuring:
  -  New enemies
  - New textures for your towers
  - New textures for the enemies
  - New textures for game UI
- **A working enemy spawning system, that works in waves of them**
- **3 Unique towers, each with its distinct attack style**
- **Working shop, used to purchase towers/upgrade them**
- **Up to 5 different tower levels for each tower**
- **Slot/placement system for the towers**
- **Seamless upgrade system for the towers**
- **Tutorial** to show you the important stuff
- **Working balance system**
  - Obtained from enemy drops
  - Used to purchase towers/upgrades
- **Final boss**
- **Main menu**
- **Game over screen**
- **End screen**
- **Intro cutscene**
- **Final cutscene**
- **Soft sound design**
- **All hand drawn**
- **Absolutely no AI usage** (literaly)

## Controls:
Most should be explained by the tutorial, in case you miss it here they are:
**Left click** on any of the pots in shop to buy that type of tower. You can then place the tower in empty yellow spots, or (if it is the same type) upgrade an existing one if you click on it instead.
And.. that's it.
